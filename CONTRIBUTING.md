# Contributing

Thanks for considering a contribution.

## Before opening a pull request

1. Check existing issues to avoid duplicating work.
2. Keep changes focused and explain the problem they solve.
3. Add or update tests for behavioural changes.
4. Run the test suite:

   ```bash
   python -m unittest discover -s tests -v
   ```

5. Update documentation when command-line behaviour or supported input changes.

## Pull request description

Include a concise summary, motivation, test commands and results, and any compatibility or operational considerations.

## Scope

Prefer small, reviewable changes. Runtime dependencies should have a clear justification and should be discussed before introduction.
